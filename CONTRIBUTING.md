# Contributing to OpenDash

Thanks for your interest! OpenDash is in the planning stage.

Please open an issue before major changes. Hardware reports should include exact model and board identifiers, firmware version, relevant chipset information, and test results, but **never passwords, tokens, personal data, or proprietary firmware without permission**.

## Licensing contributions

The project is source-available under PolyForm Noncommercial 1.0.0, not an OSI-approved open-source license. By contributing, you must have the rights to submit your work. Contributions are not automatically transferred to the project owner; copyright remains with contributors unless separately agreed. Future commercial licensing of contributed code may require separate permission from its copyright holders. We may introduce a contributor agreement before accepting significant code contributions.

## Safety

Do not submit unverified flashing instructions as safe. Never test vehicle interfaces while driving. Camera and reverse-gear behavior must be validated before use on public roads.
